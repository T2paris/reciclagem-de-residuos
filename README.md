♻️ RE:PROCESS

RE:PROCESS is a futuristic recycling game designed to make learning about waste separation fun and interactive.

In a world overwhelmed by pollution and waste, players must quickly identify falling and scattered objects and place them into the correct recycling bins. The faster and more accurately you sort, the higher your score!

The game combines educational gameplay, pixel-art visuals, and a futuristic environmental aesthetic to create an engaging way to learn about recycling.

🎮 Gameplay

Players are presented with different types of waste, such as:

📄 Paper
🧴 Plastic
🍾 Glass
🗑️ General waste

Your objective is to sort each item into the correct bin before it becomes a problem.

⭐ Features
♻️ Learn while playing — Understand how different types of waste should be separated.
🎮 Fast-paced gameplay — Test your speed and accuracy as the game gets more challenging.
🏆 Score system — Correct decisions increase your score while mistakes cost points.
📈 Progressive levels — As you advance, the challenge increases.
🤖 Futuristic world — Explore a post-apocalyptic environment where recycling is essential for rebuilding the future.
🖥️ Pixel-art aesthetic — Retro-inspired visuals combined with futuristic technology.
📚 Tutorial mode — Learn the mechanics before jumping into the main game.
🌍 The Goal

RE:PROCESS aims to show that learning about recycling doesn't have to feel like a lesson.

By turning waste separation into a game, players can develop better awareness of recycling while having fun.

Sort the waste. Earn the points. Rebuild the future.

🚀 Project

This project was created as an educational game focused on environmental awareness, recycling, and interactive learning.
